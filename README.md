# Smart Pantry Manager
Helps users reduce food waste by suggesting recipes based STRICTLY on leftover ingredients.
Student No: [YOUR NO] | Module: Mobile App Development 700

Database Choice: SQLite with Room - offline-first, no internet needed, fast CRUD, ideal for personal pantry data persistence. Chosen over Firebase because app scope is local-only and must work after closing.

How to Run:
1. Open in Android Studio Hedgehog or newer
2. Sync Gradle
3. Run on Emulator API 26+
